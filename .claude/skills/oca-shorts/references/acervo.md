# Acervo: fatos que podem ir para o ar

A base de toda referência histórica, cultural e de números da OCA Missões. Só publique um fato que esteja aqui (ou um novo com fonte que você acrescentar aqui, com data). Este arquivo existe igual nas duas skills (`oca-shorts` e `oca-carrossel`): ao editar um, copie para o outro.

Como ler a coluna **Confiança**:
- **alta**: fonte primária ou várias fontes independentes concordam.
- **média**: fonte secundária séria (artigo acadêmico citando terceiros, imprensa regional). Use com "segundo ...".
- **a confirmar**: só uma fonte fraca. Não publique sem conferir na fonte primária indicada.

Regra de escrita: atribua sempre ("segundo o astrônomo Germano Afonso", "registros das reduções indicam"). Nunca generalize "os indígenas" ou "os índios": diga **Guarani** ou **Mbyá-Guarani** quando a fonte disser, e use o presente quando o povo e o saber estão vivos ("os Guarani usam", não só "usavam").
