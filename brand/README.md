# Marca OCA Missões

## Arquivos

| Arquivo | O que é |
|---|---|
| `logo-original-150.png` | Avatar enviado pelo Jonata (150 px) |
| `logo-instagram-320.jpg` | Avatar do Instagram (320 px) |
| `oca-mark.svg` | Avatar vetorizado (quadrado com fundo barro) |
| `oca-wordmark-creme.svg` | Wordmark creme com sombras terra, para fundo barro ou escuro |
| `oca-wordmark-terra.svg` | Wordmark terra com sombras barro, para fundo creme |
| `fonts/` | Outfit e JetBrains Mono (woff2, latin + latin-ext) com licença OFL |

Os SVGs são um **traçado automático** do avatar de 320 px (potrace), não o arquivo oficial. Servem bem em vídeo e carrossel, mas podem ter pequenas diferenças de curva. Quando a OCA enviar o vetor oficial, troque os três SVGs aqui e nas pastas `assets/` e `public/brand/` dos templates.

## Paleta

| Nome | Hex | Origem e uso |
|---|---|---|
| barro | `#915729` | fundo do logo; cor da marca |
| creme | `#f8f4e1` | letras do logo; texto e personagens |
| terra | `#4a2a12` | sombras do logo; contornos, texto em fundo claro |
| noite | `#24140a` | fundo escuro, o "hoje" |
| argila | `#b9773f` | tons médios, coxilhas ao longe |
| palha | `#d9b98a` | palha da oca, texto secundário |
| mate | `#6f8a3c` | só plantas (erva-mate, brotos) |
| urucum | `#c8462c` | acento do "antes" (ancestral) |
| luz | `#3fd6c6` | acento do "hoje" (tecnologia, IA) |

Barro, creme e terra vêm do logo (amostrados do avatar). Noite, argila, palha, mate, urucum e luz são proposta desta skill: tons de terra para o passado e um único verde-água como luz da tecnologia, complementar ao barro. Ajuste se a OCA tiver um manual de marca.

## Tipografia

- **Outfit** (OFL): geométrica e arredondada, conversa com o desenho do logo. Títulos em minúsculas no vídeo, frase normal no carrossel.
- **JetBrains Mono** (OFL): etiquetas de era, datas, dados e fontes.
